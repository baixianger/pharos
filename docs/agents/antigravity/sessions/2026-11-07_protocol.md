## ACP 回合错误与审批撤回（2026-11-07）

模拟 ACP 对端在回合期间发出部分助手内容和权限请求，再对 `session/prompt` 返回 JSON-RPC 错误。修复前仅有审批撤回和全局错误，没有该回合的结束事件或历史记录，桌面视图依赖 `turnCompleted` 清除运行状态，因此可停留在运行中。修复后以原 Session 和 turn ID 记录失败回合，保留已录制内容及用户输入，撤回待处理审批，发出错误和失败结束事件。真实代码路径的模拟 ACP 测试及本地／远程前缀权限回归通过；修复前后输出分别为 `internal/evidence/2026-11-07_agy-prompt-error-before.log` 和 `internal/evidence/2026-11-07_agy-prompt-error-after.log`。

这是协议错误响应的模拟验证，不是实测进程崩溃或远程断网。进程退出时 transport 不再主动清空已经收到的 recording；部分内容是否到达读取器仍取决于退出与管道读取时序，跨进程恢复未验证。Thread 的 Mesh 到 ACP 桥接仍未实现。

## 嵌入式文本附件实验（2026-11-08）

ACP [内容规范](https://agentclientprotocol.com/protocol/v1/content)允许在 Agent 声明 `embeddedContext` 时通过 `resource` 嵌入文本或二进制数据；图片是另一种需要 `image` 能力的内容块，不应因文本实验通过而假定图片或 PDF 有效。

本机 `agy 1.5.3` 使用独立配置和工作目录建立 ACP Session，`initialize` 声明 `embeddedContext=true`。通过 `session/prompt` 传入带 `pharos://attachment/probe.txt` 标识和随机文本的 resource，真实 Agent 回复包含随机内容并返回 `end_turn`。关闭 ACP 进程后新进程 `session/load`，此次收到两个 `user_message_chunk`，类型均为 `text`：原始 `resource` 结构不在回放中，资源的文本内容及 URI 均出现在文本中。独立复测通过，证据 `internal/evidence/2026-11-08_agy-embedded-text-replay-detail.log`；测试使用自有临时目录并清理。

该实验未经过 Pharos 生产发送服务或桌面，未验证图片、二进制文件、不同模型、远程 ACP 与异常恢复。当前 `AgyLiveSessionService.send` 在 `session/prompt` 异步返回之前就将回合交给界面；服务端之后拒绝时已有失败事件，但桌面附件草稿会按初始返回提前清空。因此在接入输入框前须为附件定义可关联的异步成功/失败状态，保留不确定结果下的草稿；同时处理 Agent 将附件回放为普通文本的显示与身份边界，不能声称附件元数据保持原样。

### 生产服务与桌面输入区（2026-11-08 后续）

已为真实声明 `embeddedContext` 的 Antigravity Session 开放文本文件入口；文件以 UTF-8 文本资源嵌入 ACP `session/prompt`，使用 `pharos://attachment/…` 标识，不把本机路径假装成远端文件。无法解码为 UTF-8 或包含 NUL 的文件被拒绝；当前不支持图片和二进制附件。桌面仍限制五个文件、总计 10 MB。附件发送等待 ACP 回合完成，只有 `end_turn` 才反馈成功并清除对应草稿；期间仍可显示流式内容和处理审批，失败、取消或非完成状态保留草稿。请求已在途但连接断开时结果可能不确定，手动重试可能重复，尚无跨进程去重。
