# Cursor CLI Session 协议（2026-11-09）

版本：`agent` **2026.11.05-86047df**（本机与授权主机对齐）。证据：`internal/evidence/2026-11-09_phase-e-cursor-cli-probe.log`。

## 公开 CLI（help 可核实）
- 启动：`agent [prompt…]`；脚本输出：`--print`，`--output-format text|json|stream-json`，`--stream-partial-output`
- 模式：`--mode plan|ask` / `--plan`
- 会话：`--resume [chatId]`、`--continue`；子命令 `create-chat`、`ls`、`resume`；企业 `persist`
- 模型：`--model`、`--list-models`
- 认证：`--api-key` / `CURSOR_API_KEY`；SSH 下需 `AGENT_CLI_CREDENTIAL_STORE=file`（见持续目标 addendum）
- 默认 endpoint：`https://api2.cursor.sh`（可用 `--endpoint` / `CURSOR_API_ENDPOINT`）

## 明确未宣称
- **无 ACP / JSON-RPC Session 服务** 出现在 help；不假设与 Codex/Agy 同构的 `session/*` 协议
- 不读取 Cursor 私有数据库、桌面 GUI 状态或登录 token
