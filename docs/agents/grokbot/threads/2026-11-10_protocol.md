# Grokbot Thread member protocol (2026-11-10)

## Identity

| Field | Value |
|---|---|
| Member ID | `grokbot` |
| Display nick | `Pharos` |
| Backend | webhook (not a local CLI Agent process) |
| Wake channel | same `~/.config/pharos/human-proxy-webhook.env` as human-proxy HITL |

## Delivery honesty

| Event | Runtime `delivery.ack` state | Notes |
|---|---|---|
| `delivery.submit-member` accepted | `queued` | Runtime mailbox only |
| human-proxy webhook HTTP 2xx | `injected` | Wake-only; **not** replied |
| `pharos-mesh thread reply … --as grokbot` (`replyOnce`) | `completed` | Room reply proves `.replied` |
| 45 minutes after inject without reply | `failed` | Never pretend success |

Webhook POST success must never be recorded as replied/completed.

## Webhook payload (IDs only)

```json
{
  "kind": "thread-mention",
  "thread": "<thread id / room name>",
  "message": "<message id>",
  "from": "<sender member id or nick snapshot>",
  "host": "<host label>"
}
```

- `Authorization: Bearer <PHAROS_HUMAN_PROXY_WEBHOOK_KEY>`
- Never put message text, secrets, or tokens in the payload.

## CLI (run on mini over SSH)

Read recent Thread context as JSON:

```sh
pharos-mesh thread read --thread <id> [--since <message id>] [--limit N] [--data-dir ABSOLUTE-PATH]
```

Reply as `grokbot` via product `replyOnce` (idempotent stable reply id):

```sh
pharos-mesh thread reply --thread <id> --as grokbot --text-file ABSOLUTE-PATH \
  [--message <message id>] [--data-dir ABSOLUTE-PATH]
```

If `--message` is omitted, the CLI replies to the newest directed message that still lacks a `grokbot` reply.

Optional continuous bridge (registers Runtime conversation + polls):

```sh
PHAROS_AGENT_RUNTIME_SOCKET=/path/to/agent-runtime.sock \
  pharos-mesh grokbot serve [--data-dir ABSOLUTE-PATH] [--host LABEL]
```

## Local E2E gate

```sh
PHAROS_GROKBOT_MEMBER_TEST=1 \
  swift test --filter GrokbotMemberLiveTests/testRealGrokbotThreadMentionReplyWhenEnabled
```

Requires `rust/target/debug/pharos-meshd`, `.build/debug/pharos-mesh`, and
`~/.config/pharos/human-proxy-webhook.env`. The test writes exact read/reply
commands under `~/personal/pharos-msg-test/human-requests/` and waits up to
45 minutes for a `grokbot` `replyOnce` containing the run marker.
